# Loan-Approval-Prediction-using-Machine-Learning
Loans are a major requirement of the modern world. By this alone, banks receive a major portion of the total profit. It is beneficial for students to manage their education and living expenses, and for individuals to purchase various luxuries, such as houses and cars. But when it comes to deciding whether the applicant's profile is relevant to be granted with loan or not. Banks have to look after many aspects.

So, here we will be using machine learning algorithms to ease their work and predict whether the candidate’s profile is relevant or not, using key features like Marital Status, Education, Applicant Income, Credit History, etc.

The dataset contains 13 features:
| # | Feature Name | Description | Values / Format |
|---|---|---|---|
| 1 | **Loan** | A unique identifier for each loan application | Unique ID |
| 2 | **Gender** | Gender of the applicant | Male / Female |
| 3 | **Married** | Marital status of the applicant | Yes / No |
| 4 | **Dependents** | Number of dependents relying on the applicant | 0, 1, 2, 3+ etc. |
| 5 | **Education** | Qualification status of the applicant | Graduate / Not Graduate |
| 6 | **Self_Employed** | Whether the applicant works for themselves | Yes / No |
| 7 | **ApplicantIncome** | Main applicant income | Numeric |
| 8 | **CoapplicantIncome** | Co-applicant income | Numeric |
| 9 | **LoanAmount** | Total loan amount applied for | Numeric (in thousands) |
| 10 | **Loan_Amount_Term** | Duration of the loan term | Numeric (in months) |
| 11 | **Credit_History** | Credit history of individual's repayment of debts | 1 (Good) / 0 (Poor) |
| 12 | **Property_Area** | Location zone of the property | Rural / Urban / Semi-urban |
| 13 | **Loan_Status** | **[Target Variable]** Loan approval status | Y (Yes) / N (No) |
